DATA VOLUME
-----------
All servers share ONE volume (PVC "{{ include "minecraft-controller.claimName" . }}", {{ .Values.storage.accessMode }},
{{ .Values.storage.size }}), one folder per server. It is kept on `helm uninstall`.
Deleted servers stay in <volume>/.trash for {{ .Values.storage.trashRetentionHours }}h before being purged.
{{- if eq .Values.storage.accessMode "ReadWriteOnce" }}

WARNING: with ReadWriteOnce all pods using the volume must run on the same node,
otherwise they stay in ContainerCreating (Multi-Attach). Use ReadWriteMany to avoid this.
{{- end }}

ADMIN CREDENTIALS
-----------------
Username: {{ .Values.auth.username }}

DNS SETUP
---------
1. *.{{ $base }}        -> external IP of Service "{{ include "minecraft-controller.fullname" . }}-router" (Minecraft traffic, TCP {{ .Values.router.service.port }})
   kubectl get svc {{ include "minecraft-controller.fullname" . }}-router -n {{ .Release.Namespace }}
2. console.{{ $base }}  -> your Ingress controller IP (web traffic)
3. api.{{ $base }}      -> your Ingress controller IP (API traffic)
   (specific records for console/api take precedence over the wildcard)

Reserved names: do not create Minecraft servers named "console" or "api".
